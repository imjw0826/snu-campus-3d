# 서울대학교 3D 캠퍼스 (snu-campus-3d)

## 1. 프로젝트 소개

서울대학교 관악캠퍼스를 3D 모형으로 둘러보는 웹사이트입니다. 실제 지도 위에 건물을 올려 캠퍼스의 배치와 건물 외관을 한눈에 살펴보는 것이 목적입니다. 위치와 면적은 지도 데이터를 따르고, 높이와 외관은 사진을 참고한 추정 모형입니다.

## 2. 기술 스택

- **웹사이트:** HTML, CSS, JavaScript (빌드 과정 없는 정적 사이트)
- **3D 렌더링:** Three.js, OrbitControls
- **지도 데이터:** OpenStreetMap 건물 윤곽, 서울대 공식 캠퍼스 지도
- **배포:** GitHub Pages

## 3. 이용 방법

**웹사이트:** https://imjw0826.github.io/snu-campus-3d/

- **3D 모형 / 2D 지도**를 전환해 캠퍼스를 봅니다.
- 드래그로 회전, 우클릭으로 이동, 스크롤로 확대·축소합니다.
- **전체 캠퍼스**와 **사진 기반 모델**(외관을 자세히 만든 건물) 보기를 고릅니다.
- 건물 목록에서 건물을 찾아 상세 모델과 참고 사진을 확인합니다.
- **자료와 제작 기준**에서 데이터 출처와 모형의 한계를 볼 수 있습니다.

로컬에서 실행하려면 Python 3만 있으면 됩니다.

```bash
git clone https://github.com/imjw0826/snu-campus-3d.git
cd snu-campus-3d
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:8080 에 접속합니다. `dist/` 폴더만으로 실행·배포할 수 있고, `research/`에는 모델링에 참고한 사진과 이미지가 있습니다.
