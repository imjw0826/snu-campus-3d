# 서울대학교 3D 캠퍼스

## 실행

프로젝트 폴더의 터미널에서 실행한 뒤 http://127.0.0.1:8080 에 접속합니다.

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

## 구성

- `research/`: 모델링에 참고할 건물 사진과 디자인·지도 참고 이미지.
- `dist/`: 3D 모델, 웹 화면, 지도 데이터, Three.js, 화면에 표시할 사진. 이 폴더만으로 실행·배포할 수 있습니다.
- `dist/data/map-data.js`: 웹 표시용 건물 위치·윤곽·프로파일·사진 연결 정보.

별도 검사 코드, 조사 원장, 정리 기록, 지도 재생성 도구는 두지 않습니다.
