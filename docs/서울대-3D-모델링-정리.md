## 3. 데이터 파이프라인 (재현 순서)

```bash
python3 research/process-map.py    # 1) OSM 스냅샷 → 로컬 미터 좌표계 지도
python3 research/enrich-map.py     # 2) 공식 건물목록 237건 대조 및 보강
python3 research/fetch-photos.py   # 3) 1–15동 공식 사진 수집
```

**1) `process-map.py`** — `source/osm-campus-full.xml`을 파싱해 지도 데이터를 만듭니다.
- 원점 `[126.9545, 37.458]` 기준 **로컬 등거리 근사 투영** (x=동, z=남, 단위 m)
- 관악캠퍼스 경계 릴레이션에서 외곽 링을 이어 붙여 경계 생성
- 건물 way/relation → 윤곽(구멍 포함), 면적(신발끈 공식), 중심점(무게중심)
- 기본 모형은 윤곽의 **최소 회전 사각형(OBB)** 을 직육면체로 세운 것 (볼록껍질 + 회전 캘리퍼스)
- 높이 우선순위: OSM `height` → `building:levels` × 3.6m → **기본 4층 × 3.6m 추정**
- 1–15동은 OSM way ID 15개를 하드코딩해 매칭 (`review_ids`)
- 산출: `dist/data/campus.json`(건물 258 · 도로 685 · 녹지/수공간 80), `dist/data/buildings.geojson`

**2) `enrich-map.py`** — 공식 시설 목록과 대조합니다.
- 공식 항목의 좌표가 윤곽 안에 있거나 경계에서 12m 이내면 해당 건물에 번호·이름 부여
- 매칭 실패분은 **16 × 12m 주황색 임시 상자**로 추가하고 `area: null`, `geometryStatus: "schematic"` 표시
- 산출: `dist/data/campus.json` 갱신, `research/output/coverage.json`

**3) `fetch-photos.py`** — `map.snu.ac.kr` 공식 API가 반환한 이미지 URL만 내려받습니다.
- 1–15동 사진 + `snu-photo-research`에서 가져온 8동·14동 보조 사진 2장
- 산출: `dist/data/photos.json`, `dist/assets/photos/*.jpg`(18장), `research/output/official-targets.json`

## 4. 렌더링 (`dist/renderer.js`)

- **Three.js + OrbitControls**, `OrthographicCamera`(정사영) 기반. 초기 위치 `(-450, 2600, 2000)`
- 조명: HemisphereLight + DirectionalLight(그림자 4096², PCFSoft), ACESFilmic 톤매핑
- 지면·경계·도로(보도 2.5m / 서비스 5.5m / 일반 9m 폭)·녹지 폴리곤을 평면 레이어로 깔아 둠
- 건물마다 **① 기본 박스 ② 2D 평면 윤곽 ③ 상세 모형** 세 가지를 만들고 보기 모드에 따라 토글
- 상세 모형의 창·수평 띠·기둥·핀은 `InstancedMesh`로 일괄 처리
- 라벨은 DOM 버튼을 3D 좌표에 투영, 27px 이내 겹침은 자동 숨김
- 레이캐스팅 클릭 선택, `prefers-reduced-motion` 대응, 렌더는 `needsRender` 기반 온디맨드

## 6. 자료 출처와 한계 (문서에 명시된 내용)

**출처**
- OpenStreetMap contributors — 캠퍼스 경계·건물 윤곽·도로·녹지 (ODbL 1.0)
- 서울대학교 공식 캠퍼스 지도 `map.snu.ac.kr` — 건물 번호·이름·좌표·공식 사진
- 서울대 공식 2D 지도 PDF, `chio.snu.ac.kr`(8동), `snu.ac.kr` 뉴스(14동)
- 수집일 2026-09-20 / 사진 저작권은 각 출처에 있으며 **공개 재사용 라이선스는 확인되지 않음**

**한계 (원본 `notes`에 기록됨)**
1. OSM 윤곽은 측량된 전수 인벤토리가 아님
2. 면적은 지면 윤곽 기준 근삿값 — 연면적·건축면적이 아님
3. **지형 고도는 반영하지 않은 평면 지도**
4. OSM `height` 태그가 있는 경우를 제외한 모든 높이는 추정
5. 1–15동 외관은 사진 참고 간략화 — 사진측량·정밀 실측 모델이 아니며 보이지 않는 면은 추정
6. 주황색 임시 상자(41건)는 위치만 확인된 것이며 16×12m는 임의의 시각화 기본값
7. 7동은 2026년 증축 공사 중으로 기존 외관 기준 모형
